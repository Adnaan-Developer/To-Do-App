# 📝 To-Do List App

A modern and responsive To-Do List application built with React and Tailwind CSS. Manage daily tasks, track your progress, and stay organized with a clean and interactive user interface.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Persist tasks using Local Storage
- 🌙 Dark mode support
- 📱 Responsive design
- ⚡ Interactive user interface

## 🛠️ Tech Stack

- **React** — Building reusable UI components
- **Tailwind CSS** — Styling and responsive design
- **JavaScript** — Application logic
- **Local Storage** — Persisting tasks in the browser
- **Lucide React** — Icons

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Adnaan-Developer/To-Do-App.git
```

### 2. Navigate to the project directory

```bash
cd todo-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
